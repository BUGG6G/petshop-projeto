# Plataforma Web PetShop - Fase 1

Este repositório contém a entrega da **Fase 1** do Projeto da Disciplina. O objetivo principal desta etapa foi a construção da estrutura de conteúdo de uma plataforma de e-commerce e agendamentos para um PetShop.

## Tecnologias Utilizadas
* **HTML5 Puro**: Utilização estrita de tags semânticas para estruturação do conteúdo, sem qualquer estilização de CSS ou JavaScript.

## Funcionalidades Estruturadas
* **Cabeçalho**: Identificação da marca e menu de navegação por âncoras internas.
* **Vitrine de Produtos**: Exibição de 3 categorias obrigatórias com 2 produtos em cada (contendo imagem, descrição técnica e valor):
    1. Acessórios
    2. Rações Não Perecíveis
    3. Higiene e Limpeza
* **Tabela de Serviços**: Apresentação dos serviços de Banho e Tosa detalhando escopo, valores e as opções com ou sem o adicional de **Tele-busca**.
* **Rodapé**: Informações de direitos autorais e dados de contato do PetShop.
